# Voice profile

How the candidate writes, measured from their own texts. Not filled yet: the setup (or a
re-measure) writes it with `scripts/voice.py`. Never invent a voice: if there are no samples,
write factually and say the voice could not be measured.

Sources, in priority order:
1. An explicit style guide or writing-style skill in the pool.
2. Texts the candidate wrote that are in the pool (CVs, cover letters, profiles, posts).
3. Samples pasted by the candidate, saved in `profile/samples/`.
4. None: neutral factual writing, flagged in every review.
