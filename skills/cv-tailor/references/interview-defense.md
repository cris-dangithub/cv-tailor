# Human lie detector

Rule: **every line of the CV must be defensible by talking about it for 5 minutes in an
interview.** If it can't be, soften it or delete it.

| CV line | Likely question | Defensible? |
|---|---|---|
| "Angular expert" | Tell me about the most complex project you built and what went wrong | Never used it: NO → delete |
| "Cut costs by 20%" | How did you measure it? Against which baseline? | No source for the number: NO → drop the number |
| "Led the team" | How many people? Which decisions were yours? | Only coordinated a task: soften |

Safe rewrite: instead of claiming a capability they don't have, tell the useful true version.

- ❌ "Specialist in modern frontend architectures (Angular, Vue, Astro, NestJS)"
- ✅ "Built projects with React and knows in depth the architecture of the ones they set up"

In the review file, list 3–5 likely interview questions with the line that triggers each. It is
preparation and a last truth test. A CV that passes the filter only gets the interview; there,
no AI helps.
